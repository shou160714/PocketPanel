FEATURES

PocketPanel でできること

ゲーム、配信、プログラミング、日常のデスクワークまで。用途に合わせてページを切り替えられます。

リアルタイムPC監視

CPU・GPU使用率や温度、VRAM、メモリ、ディスク容量、ネットワーク速度・Pingをグラフで常時表示。実行中プロセスの確認・制御にも対応。

Control Deck & メディア操作

アプリ起動、URL、ショートカットキー、マクロをワンタップ実行。音量ダイヤル、マイク＆カメラハブ、OBS操作、Spotify等の音楽ランチャーも搭載。

AIコーディング＆開発支援

Claude・Codex・Antigravity の利用枠やリセット時刻、消費ペースを可視化。ローカルセッションの監視やスマホからの許可応答、GitHub CI確認にも対応。

SwitchBot スマートホーム連携

SwitchBot API 連携（Home Assistant も対応）で、デスクに座ったままエアコンの温度・風量調整、照明の調光、スイッチのON/OFFを手元で操作できます。

ビジュアルエディター＆テーマ

PCブラウザ上でドラッグ＆ドロップ配置。クールなダークUIからかわいいパステルテーマ、Simple / PROモード切替、縦横画面ロックまで自由自在です。

Wi-Fi / VPN 自動フォールバック

QRコードを1回読み取るだけでLAN・VPN（Tailscale等）アドレスを一括保存。自宅では高速LAN、外出先ではVPNへ自動で切り替わります。

SCREENSHOTS

実際の画面イメージ

プロ向けの情報密度が高いレイアウトから、癒やされるパステルテーマまで多彩に切り替えられます。

ホームダッシュボード

時計、天気、Spotify再生コントロール、CPU/GPU/RAM/ネットワークのグラフを1画面に集約。

HOW IT WORKS

かんたん 3 ステップで始められる

難しいポート開放やIPアドレスの手入力は不要です。

01

PCにエージェントを入れる

Windows（Microsoft Store）に PocketPanel エージェントをインストールして起動します。常駐トレイアイコンからいつでも設定画面を開けます。

02

スマホにアプリを入れる

Android（Google Play）または iOS（App Store）にモバイル版 PocketPanel をインストールします。古いスマホやタブレットの再利用にも最適です。

03

QRコードをスキャン

PC画面に表示されたペアリング用QRコードをスマホで読み取り、確認コードを承認すれば接続完了。すぐにパネルが表示されます。

PRIVACY & SECURITY

ローカル完結で、ずっと安心。

PocketPanel は開発者のクラウドサーバーを経由しません。アカウント登録も、テレメトリや利用状況データの収集も一切行いません。 ペアリングされた端末同士が、認証・暗号化された通信で直接やり取りします。

FAQ

よくある質問

PocketPanel を使うには何が必要ですか？

PC用のデスクトップエージェント（Windows版 / 今後のmacOS版）と、スマートフォン・タブレット用のモバイルアプリ（Android / iOS）の両方が必要です。同じWi-FiまたはVPN上でQRコードを読み取るだけで接続できます。

アカウント登録や月額課金、クラウドへのデータ送信はありますか？

いいえ、アカウント登録やクラウドサーバーへのデータ送信はありません。すべての設定やPCステータス情報はローカル環境とペアリング済み端末の間でのみ通信されます。

外出先や別のWi-FiからでもPCを監視・操作できますか？

はい。TailscaleなどのVPNアドレスもQRコードペアリング時に一括保存されるため、自宅Wi-Fiでは低遅延のLAN接続、外出先ではVPN経由へ自動で切り替わります。

SwitchBotの操作にはハブが必要ですか？

SwitchBot API（v1.1）経由でデバイスと通信するため、SwitchBotアプリ上でAPIトークン・シークレットを発行し、対応するSwitchBotハブ製品等と連携しているデバイスを操作できます。
